# Sales Performance Analysis (Excel Dashboard)
Project Overview,
this project analyzes sales performance data using Microsoft Excel to uncover insights on revenue, profit, customer trends, and regional performance.
Tools Used
Microsoft Excel (Pivot Tables, Charts, Data Cleaning).
Key Metrics
- Revenue: 2.33B  
- COGS: 1.86B  
- Profit: 465.7M  
- Customers: 2,098  
 Key Insights
- Sofa Classic generated the highest profit  
- Peter generated the highest revenue  
- Customer count dropped sharply in May
